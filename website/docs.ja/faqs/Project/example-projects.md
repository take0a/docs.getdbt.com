Yes!

* **Quickstart Tutorial:** [クイックスタート ガイド](/docs/get-started-dbt) で独自のサンプル dbt プロジェクトを構築できます。
* **Jaffle Shop:** 架空の電子商取引ストアのデモ プロジェクト (チュートリアルに密接に関連) ([メイン ソース コード](https://github.com/dbt-labs/jaffle-shop) と [duckdb を使用したソース コード](https://github.com/dbt-labs/jaffle_shop_duckdb))
* **GitLab:** Gitlab の内部 dbt プロジェクトはオープンソースであり、dbt を大規模に使用する方法の優れた例です ([ソース コード](https://gitlab.com/gitlab-data/analytics/-/tree/master/transform/snowflake-dbt))
* **dummy-dbt:** PostgresのSakilaデータベースにdbtシード、モデル、スナップショット、テストデータを格納するコンテナ化されたdbtプロジェクトです。このプロジェクトはテストや実験に使用できます（[ソースコード](https://github.com/gmyrianthous/dbt-dummy)）
* **Google Analytics 4:** Google Analytics 4 BigQuery エクスポートをさまざまなモデルに変換するデモ プロジェクト ([ソース コード](https://github.com/stacktonic-com/stacktonic-dbt-example-project)、[ドキュメント](https://stacktonic.com/article/google-analytics-big-query-and-dbt-a-dbt-example-project))
* **Make Open Data:**  フランスのオープンデータ（住宅、人口統計、地理など）に関するテスト、ドキュメント、CI/CD（GHA）を備えた本番環境レベルのELTです。大量かつ曖昧なデータでの学習に使用できます。貢献を歓迎します（[ソースコード](https://github.com/make-open-data/make-open-data)、[ドキュメント](https://make-open-data.fr/)）

このリストに追加するサンプル プロジェクトがある場合は、下の **Edit this page** をクリックして編集を提案してください。
