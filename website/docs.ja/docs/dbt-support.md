dbtのサポートは、以下のチャネルを通じてすべてのユーザーにご利用いただけます。

- 専任のdbtサポートチーム（dbt Cloudユーザー）。
- [コミュニティフォーラム](https://discourse.getdbt.com/)。
- [dbtコミュニティSlack](https://www.getdbt.com/community/join-the-community/)。
  
## dbt Core サポート

コマンドライン (CLI) で開発していて、ご質問やサポートが必要な場合は、[コミュニティフォーラム](https://discourse.getdbt.com/) または [dbt コミュニティ Slack](https://www.getdbt.com/community/join-the-community/) を通じて、dbt コミュニティにご連絡ください。

## dbt Cloud サポート

dbt Cloud をご利用のお客様は、[メール](mailto:support@getdbt.com) または dbt Cloud ナビゲーションから「**サポートチケットを作成**」をクリックして、グローバル dbt サポートチームにお問い合わせいただけます。

### サポートチケットを作成する

dbt Cloud でサポートチケットを作成するには：
1. dbt Cloud のナビゲーションで、**Help & Guides** をクリックします。
2. **Create a support ticket** をクリックします。
3. フォームに入力し、**Create Ticket** をクリックします。
4. dbt サポートチームのメンバーがメールでチケットに返信します。

<Lightbox src="/img/create-support-ticket.gif" title="Create a support ticket in dbt Cloud" />

### dbt Support Assistant に質問する

dbt Support Assistant は、よくある質問に対して AI が即座に回答を生成する AI ウィジェットです。この機能は dbt Cloud ユーザーが利用可能で、トラブルシューティングに関する質問への回答、機能概要の提供、関連ドキュメントへのリンクの提供などに役立ちます。

dbt Support Assistant AI ウィジェットは、分析ワークフローを高速化するコード生成を支援する強力な AI エンジンである [dbt Copilot](/docs/cloud/dbt-copilot) とは別のものです。dbt Support Assistant は、ドキュメント作成やトラブルシューティングに関する質問への回答に重点を置いています。dbt Cloud で AI 機能を有効または無効にしても、dbt Support Assistant の可用性には影響しません。

:::info
あらゆるシナリオにおいて、AIからの応答で受信した情報は、弊社のドキュメントを参照して検証することをお勧めします。サポートアシスタントから提供された情報に誤りがある場合は、[サポートにお問い合わせ](mailto:support@getdbt.com)ください。
:::

### サポートプランとリソース

お客様の組織におけるdbt Cloudの導入と活用を支援いたします。[ドキュメント](https://docs.getdbt.com/)や[コミュニティフォーラム](https://discourse.getdbt.com/)で回答が見つからないご質問は、サポートチームが「dbtでお手伝い」いたします。

- **エンタープライズプラン** &mdash; 優先[サポート](#エンタープライズサポートの重大度レベル)、オプションのプレミアムプラン、強化されたSLA、導入支援、専任管理、価格帯に応じたdbt Labsセキュリティレビューをご利用いただけます。
- **開発者およびチームプラン** &mdash; 24時間365日サポート（サービスレベル契約（SLA）はございません。エンタープライズプランに関するお問い合わせは[営業担当まで](https://www.getdbt.com/pricing/)までお問い合わせください）。
- **サポートチームによるサポート** &mdash; プロジェクトのセットアップ、ログインの問題、エラーの理解、プライベート パッケージのセットアップ、新しい GitHub アカウントへのリンク、[har ファイルの生成方法](/faqs/Troubleshooting/generate-har-file) など、[dbt Cloud に関するよくある質問](/category/troubleshooting) への対応。
- **リソース ガイド** &mdash; 効果的なヘルプの求め方については、[ガイド](/community/resources/getting-help) をご覧ください。

## dbt Cloud Enterprise アカウント

dbt プロジェクトのトラブルシューティングに関する基本的なサポート。
マクロ、モデル、dbt Labs パッケージのエラーや問題に関するサポート。
戦略的なアドバイス、ベストプラクティス、または拡張に関するご相談は、アカウントチームまでお問い合わせください。

dbt Cloud Enterprise プランをご利用のお客様には、dbt プロジェクトに関する問題のトラブルシューティングに関する基本的なサポートも**提供しています**。
- **期待どおりに動作しない問題があります...**
    - 作成したマクロで問題が発生しました...
    - 構築中の増分モデルで問題が発生しました...
    - dbt_utils や audit_helper などの dbt Labs パッケージで問題が発生しました...
- **このエラーの理解とトラブルシューティングについてサポートが必要です...**
    - `Server error: Compilation Error in rpc request (from remote system)     'dbt_utils' is undefined`
    - `SQL compilation error: syntax error line 1 at position 38 unexpected '<EOF>'.`
    - `Compilation Error Error reading name_of_folder/name_of_file.yml - Runtime Error Syntax error near line 9`

アカウントチームに尋ねるべき質問の種類：
- 会社の構造とニーズに基づいて、dbtプロジェクト、環境、ジョブをどのように設定すればよいでしょうか？
- アカウントを拡大したいのですが、人員を増やし、トレーニングを行うにはどうすればよいでしょうか？
- 来年のデータロードマップはこちらです。dbtがどのようにロードマップに位置付けられるか、そして目標達成に役立つのにまだ活用されていない機能は何かについてお話しいただけますか？
- 契約更新の時期が近づいてきましたが、どのような選択肢がありますか？

### エンタープライズサポートの重大度レベル

サポートチケットには、問題がお客様のビジネスに与える影響に基づいて重大度レベルが割り当てられます。重大度レベルはdbt Labsによって割り当てられ、割り当てられたレベルに応じて、お客様が受けるサポートの優先度が決まります。チケットへの具体的な応答時間や、エンタープライズアカウントのSLAに関するその他のご質問については、エンタープライズ契約書をご覧ください。

| Severity Level | Description |
| -------------- | ----------- |
| Severity Level 1 | サブスクリプションまたは重要な機能の使用または継続使用を不可能にするエラー。サブスクリプションは動作せず、代替手段はありません。 | 
| Severity Level 2 | 機能障害があり、回避策はありませんが、サブスクリプションは動作します。 | 
| Severity Level 3 | 機能は失敗していますが、回避策は存在します。 | 
| Severity Level 4 | クライアントのサブスクリプションへのアクセスや使用にほとんど影響がないエラー、またはクライアントから一般的な質問や機能強化のリクエストがあるエラー。 | 

## フィードバックを送信する

dbt Cloud または dbt Core に関するフィードバックや機能リクエストを送信してください。

#### dbt Cloud に関するフィードバックまたは機能リクエストをお寄せください
1. dbt Cloud のナビゲーションで、**Leave feedback** をクリックします。
2. **Leave feedback** ポップアップでフォームに入力します。
3. 関連ファイルをフィードバックフォームにアップロードします（任意）。
4. dbt Labs からフィードバックに関する連絡を受けるかどうかを確定します（任意）。
5. **Send Feedback** をクリックします。

<Lightbox src="/img/docs/leave-feedback.gif" title="Leave feedback in dbt Cloud" />

#### dbt Core に関するフィードバックや機能リクエストをお寄せください。
- [GitHub で Issue を作成](https://github.com/dbt-labs/dbt-core/issues)

## 外部サポート

SQLの記述、プロジェクト全体のパフォーマンスレビュー、またはdbtプロジェクト構築の支援が必要な場合は、以下のページをご覧ください。
- [dbtコンサルティングパートナー](https://partners.getdbt.com/english/directory/)の一覧
- dbt Labsの[サービス](https://www.getdbt.com/dbt-labs/services/)
