title: dbt Explorer でドキュメントにアクセスするにはどうすればよいですか?
description: "読み取り専用シートを使用してドキュメントを共有する"

id: sharing-documentation
---

dbt Cloud を使用してプロジェクトをデプロイし、[Team プランまたは Enterprise プラン](https://www.getdbt.com/pricing/) をご利用の場合は、dbt Explorer を使用してプロジェクトの [リソース](/docs/build/projects) (モデル、テスト、メトリックなど) とその <Term id="data-lineage">リネージ</Term> を表示し、最新の本番環境の状態をより深く理解することができます。

ナビゲーションの [Explore] リンクをクリックすると、dbt Cloud で dbt Explorer にアクセスできます。プロジェクトのドキュメントには、最大 5 人の読み取り専用ユーザーがアクセスできます。

dbt Cloud 開発者プランおよび dbt Core ユーザーは、[dbt Docs](/docs/collaborate/build-and-view-your-docs#dbt-docs) を使用できます。これは基本的なドキュメントを生成しますが、dbt Explorer と同じ速度、メタデータ、可視性は提供されません。
