<Constant name="cloud" /> を使用してプロジェクトをデプロイし、[Starter, Enterprise, or Enterprise+ plan](https://www.getdbt.com/pricing/) をご利用の場合は、dbt Explorer を使用してプロジェクトの [リソース](/docs/build/projects) (モデル、テスト、メトリックなど) とその <Term id="data-lineage">リネージ</Term> を表示し、最新の本番環境の状態をより深く理解することができます。

ナビゲーションの **Explore** リンクをクリックすると、<Constant name="cloud" /> で <Constant name="explorer" /> にアクセスできます。プロジェクトのドキュメントには、最大 5 人の読み取り専用ユーザーがアクセスできます。

<Constant name="cloud" /> 開発者プランおよび <Constant name="core" /> ユーザーは、[dbt Docs](/docs/explore/build-and-view-your-docs#dbt-docs) を使用できます。これは基本的なドキュメントを生成しますが、<Constant name="explorer" /> と同じ速度、メタデータ、可視性は提供されません。
