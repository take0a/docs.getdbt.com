
:::info
[dbt Cloud "最新" リリーストラック](/docs/dbt-versions/cloud-release-tracks)およびdbt Core v1.9以降、`.sql`ファイルで設定ブロックを使用してスナップショットを定義する方法は従来の方法です。最新の[スナップショット固有の設定](/docs/build/snapshots#configuring-snapshots)を使用して、YAML形式でスナップショットを定義できます。新しいスナップショットには、これらの最新の設定を使用することをお勧めします。既存のスナップショットに適用する場合は、[移行](#snapshot-configuration-migration)を行う必要があります。
:::
