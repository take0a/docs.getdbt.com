<Constant name="cloud_ide" /> では、キーボードショートカット、機能、開発のヒントなどを提供し、作業を迅速化し、生産性を向上させることができます。

この <Constant name="cloud_ide" /> ページを使用すると、よく使用する操作を簡単に参照できます。

| Shortcut description | macOS | Windows |
|--------|----------------|------------------|
| 行コメントの追加、タブの表示サイズの変更、変更されたモデルの構築、エディターのフォント サイズの変更など、開発に役立つエディターのショートカットの完全なリストを表示します。 | Fn-F1 | Fn-F1 |
| 開くファイルを選択します。 | Command-O | Control-O |
| 現在アクティブなエディター タブを閉じます。 | Option-W | Alt-W |
| コードをプレビューします。 | Command-Enter | Control-Enter |
| コードをコンパイルします。 | Command-Shift-Enter | Control-Shift-Enter |
| エディターに dbt 関数のリストを表示します。 | アンダースコア 2 つ `__` を入力します | アンダースコア 2 つ `__` を入力します |
| コマンド パレットを開いて、dbt コマンドとアクションを呼び出します。 | Command-P / Command-Shift-P | Control-P / Control-Shift-P |
| 複数の行を選択してエディターでマルチ編集します。 | Option-クリック / Shift-Option-Command / Shift-Option-クリック | Alt キーを押しながらクリック |
| IDE の下部にある [**呼び出し履歴ドロワー**](/docs/cloud/dbt-cloud-ide/ide-user-interface#invocation-history) を開きます。 | Ctrl + バックティック (または Ctrl + `) | Ctrl + バックティック (または Ctrl + `) |
| 選択したコードにブロックコメントを追加します。SQL ファイルでは、SQL 構文 `(/* */)` ではなく、Jinja 構文 `({# #})` が使用されます。<br /> <br /> Markdown ファイルでは、Markdown 構文 `(<!-- -->)` が使用されます。 | Command + Option + / | Ctrl + Alt + / |
