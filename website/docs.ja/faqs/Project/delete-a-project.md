dbt Cloud でプロジェクトを削除するには、アカウント所有者であるか、管理者権限を持っている必要があります。

1. dbt Cloud の左側のメニューでアカウント名をクリックし、**Account settings** を選択します。

<Lightbox src="/img/docs/dbt-cloud/Navigate-to-account-settings.png" title="Navigate to account settings" />

2. **Account Settings** で、**Projects** を選択します。**Projects** ページから削除したいプロジェクトをクリックします。
3. **Project Details** の右下にある編集アイコンをクリックします。同じ詳細ビューの左側に **Delete** オプションが表示されます。
4. **Delete** を選択します。追加のパスワード入力を必要とせず、ユーザーを直ちに削除するには、アクションを確定します。アカウントパスワードの入力は求められず、確定後すぐにプロジェクトが削除されます。プロジェクトを削除すると、このアクションは元に戻せません。

<Lightbox src="/img/docs/dbt-cloud/delete_projects_from_dbt_cloud.png" title="Delete projects" />
